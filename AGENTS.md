# Goodchords

## О проекте

Goodchords — TypeScript-библиотека по музыкальной теории без пользовательского интерфейса. Публичный API экспортирует `Note`, `Interval`, `Chord` и `Scale`. Nx-монорепозиторий подготовлен для добавления приложений, включая будущий Angular-интерфейс.

## Структура

- `packages/goodchords` — публикуемая npm-библиотека `goodchords`.
- `packages/goodchords/src` — доменная логика и colocated-тесты `*.test.ts`.
- `packages/goodchords/src/index.ts` — единая публичная точка входа.
- `apps` — место для будущих приложений; приложение может зависеть от библиотеки, но не наоборот.
- `nx.json` — inferred targets и общая конфигурация Nx.

Менеджер пакетов — npm. Используйте Node.js `^22.12.0`.

## Команды

```bash
npm run lint
npm test
npm run typecheck
npm run build
```

Запускайте задачи через Nx, а не напрямую через ESLint, Vitest, TypeScript или Rollup. Для конкретной задачи допустима форма `npx nx <target> goodchords`.

## Правила изменений

- Сохраняйте доменную библиотеку независимой от Angular и другого UI.
- Не меняйте публичные экспорты и package exports без явного требования.
- Обновляйте colocated-тесты при изменении поведения.
- Сборка должна сохранять ESM, CommonJS и декларации типов.
- Не разделяйте сущности на отдельные Nx-библиотеки механически: `Chord` и `Scale` пока имеют циклическую зависимость.
